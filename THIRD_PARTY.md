# Third-party projects and applications

BrandFleet coordinates existing infrastructure and software. The projects below retain their own authorship, notices and licenses. This repository does not bundle or relicense their server distributions, Android images or APKs.

| Project | Role in the reference architecture | Upstream |
| --- | --- | --- |
| Proxmox VE | Physical host and VM management | [proxmox.com](https://www.proxmox.com/en/proxmox-virtual-environment/overview) |
| LXC | Linux container runtime | [lxc/lxc](https://github.com/lxc/lxc) |
| Android Open Source Project | Android operating system | [source.android.com](https://source.android.com/) |
| redroid | Android cloud image/runtime foundation | [remote-android/redroid-doc](https://github.com/remote-android/redroid-doc) |
| Debian | Native Linux userspace and shared services | [debian.org](https://www.debian.org/) |
| Node.js / Python | Dashboard and private controller runtimes | [nodejs.org](https://nodejs.org/) · [python.org](https://www.python.org/) |
| Traefik | HTTPS ingress and routing | [traefik/traefik](https://github.com/traefik/traefik) |
| Nextcloud | Files, Talk, Calendar, Contacts and Deck | [nextcloud/server](https://github.com/nextcloud/server) |
| Postfix / Dovecot | SMTP and mailbox services | [postfix.org](https://www.postfix.org/) · [dovecot.org](https://www.dovecot.org/) |
| Rspamd / ClamAV | Mail filtering and antivirus | [rspamd.com](https://rspamd.com/) · [clamav.net](https://www.clamav.net/) |
| Roundcube | Browser webmail | [roundcube/roundcubemail](https://github.com/roundcube/roundcubemail) |
| coturn / PocketBase | TURN relay and application backend | [coturn/coturn](https://github.com/coturn/coturn) · [pocketbase/pocketbase](https://github.com/pocketbase/pocketbase) |
| Tailscale | Selected private networking and planned exit-node routing | [tailscale.com](https://tailscale.com/) |
| Coolify | Requested destination for website deployment on Debian | [coolify.io](https://coolify.io/) |
